# 云雀协作 安装指南

## 一、系统要求
- Windows：Windows 10 及以上（64 位）
- macOS：macOS 11 Big Sur 及以上
- iOS：iOS 14 及以上
- Android：Android 8.0 及以上
- 网络：建议 2 Mbps 以上，需可访问官网和 API 域名

## 二、Web 端使用
无需安装。使用 Chrome、Edge 或 Safari 最新版访问官网，登录后即可使用。

## 三、Windows 桌面端安装步骤
1. 访问官网“下载”页面，下载 Windows 安装包（.exe）。
2. 双击安装包，若系统提示，请允许运行。
3. 选择安装位置，勾选“创建桌面快捷方式”，点击“安装”。
4. 等待进度条完成，点击“完成”启动云雀协作。
5. 使用邮箱验证码或企业账号登录，加入团队空间。

## 四、macOS 桌面端安装步骤
1. 从官网下载 .dmg 文件。
2. 打开 .dmg，将云雀协作图标拖入“应用程序”文件夹。
3. 在“启动台”或“应用程序”中打开，若提示安全确认，选择“打开”。
4. 登录账号并授权通知权限。

## 五、iOS 与 Android 安装
- iOS：在 App Store 搜索“云雀协作”，点击获取并安装。
- Android：在应用商店搜索“云雀协作”，或从官网下载 APK 安装。
- 安装后打开应用，登录并开启通知。

## 六、企业批量部署
企业版管理员可下载 MSI 或 PKG 安装包，通过 MDM 或组策略批量部署。详细文档请联系客户成功经理。

## 七、常见安装问题
- 安装失败：检查系统版本、磁盘空间和管理员权限。
- 无法启动：关闭杀毒软件后重试，或重新下载安装包。
- 登录异常：确认网络可访问官网，检查账号是否被禁用。
- 移动端收不到通知：在系统设置中允许云雀协作发送通知。

## 八、更新与卸载
- 更新：桌面端会自动检查更新，也可在设置中手动检查。
- 卸载：Windows 在“设置 > 应用”中卸载；macOS 将应用拖入废纸篓；移动端长按图标卸载。

## 九、获取帮助
在应用内“帮助与反馈”提交工单，或发送邮件至 support@example.com，工作日 1 个工作日内回复。
