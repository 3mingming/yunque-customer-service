# 云雀协作 价格说明

## 一、套餐概览
云雀协作提供免费版、专业版和企业版。专业版分为个人会员和团队会员。

| 版本 | 计费方式 | 价格 | 适用对象 |
|------|----------|------|----------|
| 免费版 | 免费 | 0 元 | 个人或小团队试用 |
| 专业版·个人会员 | 月付 | 49 元/月 | 个人用户 |
| 专业版·个人会员 | 年付 | 499 元/年 | 个人用户 |
| 专业版·团队会员 | 月付 | 99 元/人/月 | 团队 |
| 专业版·团队会员 | 年付 | 999 元/人/年 | 团队 |
| 企业版 | 按年合同 | 联系销售 | 中大型企业 |

## 二、免费版
- 价格：0 元
- 成员上限：5 人
- 功能：任务看板、基础文档、日程、通知
- 存储：1 GB
- API 与 Webhook：不支持
- 客服：应用内工单（工作日回复）

## 三、专业版·个人会员
- 价格：月付 49 元；年付 499 元（约 41.6 元/月）
- 席位：1 个
- 功能：无限任务、无限文档、高级筛选、文件上传
- 存储：10 GB
- API 与 Webhook：支持
- 试用：可享受 14 天专业版团队会员试用

## 四、专业版·团队会员
- 价格：月付 99 元/人；年付 999 元/人（约 83.3 元/人/月）
- 席位：按实际成员数计费，可随时增减
- 功能：包含个人会员全部功能，另支持团队空间、角色权限、管理员控制台、操作日志
- 存储：100 GB（团队共享）
- API 与 Webhook：支持
- 试用：14 天免费试用，无需绑定信用卡

## 五、企业版
- 价格：根据席位、合同期限和所需服务定制，请联系销售
- 功能：包含专业版全部功能，另支持 SSO、双重验证、审计日志、数据保留策略、专属客户成功经理、SLA 保障
- 存储：可扩展，按合同约定
- 部署：支持公有云或私有化部署（需单独评估）
- 发票与合同：支持对公转账、开具增值税专用发票

## 六、计费与续费规则
- 计费周期：月付按自然月，年付按 365 天。
- 自动续费：默认开启，可在“设置 > 账单”中关闭。
- 续费价格：按续费时官网公示价格执行。
- 升级：从低版本升级到高版本，按剩余服务期限折算差价，立即生效。
- 降级：从高版本降级到低版本，在下一计费周期生效，不退还已支付差价。
- 增删席位：团队会员可随时增减，费用按剩余天数折算，在下期账单中多退少补。

## 七、优惠与试用
- 年付优惠：年付价格已包含约 8.4 折优惠。
- 教育与非营利：符合条件的学校、非营利组织可申请额外折扣，请联系 support@example.com。
- 免费试用：新用户可享受 14 天专业版团队会员试用，到期后自动降级为免费版，不会自动扣费。
- 活动优惠：官网不定期推出优惠活动，以活动页面说明为准。

## 八、支付方式
- 个人与团队：支持支付宝、微信支付、银联卡。
- 企业版：支持对公转账，可签订合同。
- 所有价格均为人民币含税价。

## 九、发票
- 可开具电子普通发票或增值税专用发票。
- 申请路径：应用内“帮助与反馈”提交工单，或发送邮件至 support@example.com。
- 若已开具发票，退款前需先退回发票或配合冲红，否则退款可能延迟。

## 十、退款
退款规则详见《退款政策》。简要说明：
- 首次购买专业版：付款后 7 个自然日内，且未使用超过 3 个付费功能模块，可申请全额退款。
- 专业版续费：付款后 3 个自然日内且未使用新增权益，可申请全额退款。
- 企业版：按合同约定执行。

## 十一、联系与帮助
- 应用内：帮助与反馈
- 邮箱：support@example.com
- 工作日 1 个工作日内回复
